## 1. 该不该用代码做

**适合代码的画面**：文字、图形、图表、UI、Logo、线稿、几何、粒子、地图色块、数据驱动的画面。
**适合代码的需求**：时间轴要精确到帧；要反复改；要出多个版本（横竖屏、15/30 秒、多语言）；要和配音逐句对齐。

**不适合**：
- 真人、写实场景、复杂角色表演 → 用视频生成模型（Seedance、即梦、Veo 等）。
- 只是剪已有素材、加字幕 → 用剪辑软件。

两者可以混用：AI 生成的图片或视频片段当素材嵌进 HTML（嵌视频的做法见 determinism.md 第 5 节）。

## 2. 片型（按用途选结构）

先问一句"这条片子给谁看、看完记住什么"，再对号入座。片型决定结构骨架和时长分配；配方在 recipes.md。

| # | 片型 | 用途 | 典型时长 | 结构骨架 |
|---|---|---|---|---|
| 1 | 产品 / 发布片 | 新功能、App、SaaS 上线 | 15–30s | 钩子 → 产品的一个核心动作 → 2–3 个能力 → 证据 → 品牌落版 |
| 2 | Logo 演绎 / 片头片尾 | 账号片头、品牌落版 | 4–8s | 一个形状 → 变形或组装 → 落版定格 1s |
| 3 | 动态字体 / 金句 | 观点、宣言、歌词 | 8–20s | 按短语出词，词本身承担画面结构 |
| 4 | UI 形变循环 | 展示交互细节 | 8–15s 循环 | 一个形状从不切断，连续变成 8–12 个 UI 状态 |
| 5 | 炫技 showreel | 个人作品集、账号定位 | 10–20s | 一个概念升级 3 次，而不是技巧清单 |
| 6 | 概念科普 / 讲解 | 原理、知识点 | 30–90s | 问题 → 直觉 → 机制 → 反直觉点 → 结论 |
| 7 | 配音驱动竖屏短视频（讲史、知识） | 抖音、视频号口播配画面 | 跟配音走 | 一句话一个视觉事件（另见 voiceover.md） |
| 8 | 数据故事 | 数字对比、趋势、尺度 | 15–45s | 一个数字 → 尺度参照 → 对比 → 结论 |
| 9 | 3D 产品 / 场景 / 尺度穿越 | 产品拆解、建筑、"从地球到原子" | 10–40s | 一条连续运镜贯穿 |
| 10 | 游戏 / 像素演出 | 开宝箱、升级、成就 | 3–8s 一段 | 蓄力 → 爆发 → 奖励 → 余韵 |

**互动网页不是视频**。游戏、可拖拽的模型要录成视频，必须加三样东西：自动演示模式、固定随机种子、seek(t)。做法见 recipes.md 第 10 节。

## 3. 技术栈（按画面选工具）

| 技术 | 擅长 | 主要的坑 | 什么时候选 |
|---|---|---|---|
| DOM + CSS（JS 每帧写样式） | 文字排版、卡片、字幕、UI | 不能让 CSS transition / animation 自己跑 | 文字为主的片子，首选 |
| SVG | 线稿、图标、描边路径、图表、Logo | 节点上千会慢；CSS 变量要写进 style | 线条和图形为主 |
| Canvas 2D | 粒子、大量元素、手绘感、像素风 | 文字排版要自己算；注意像素比 | 元素多、要逐像素控制 |
| GSAP | 复杂编排、错峰、现成缓动 | 时间线必须 paused，由 seek(t) 驱动 | 想用它的缓动和 stagger |
| Three.js / WebGL | 3D、光照、材质、景深 | 版本要锁定；无头浏览器跑 WebGL 要软件渲染；慢 | 只在要讲空间关系时 |
| 片段着色器 | 抽象背景、raymarch、流体感 | 难调、难读 | 抽象视觉或背景层 |

**默认分层**：文字放 DOM 层（清晰、好换字体），图形放 SVG 或 Canvas，3D 场景里的标签用"每帧投影过来的 HTML 层"，不做 3D 文字。

**能 2D 就不上 3D。** 3D 只在要讲清分层、部件、摆放、尺度时才值得；否则它带来的是渲染慢、调试难、录制坑多。

**能 SVG/DOM 就不用 Canvas。** DOM 和 SVG 的东西可以直接在开发者工具里看和改，Canvas 画出来就只是像素。

常见组合：
- Canvas 粒子背景 + DOM 文字层
- SVG 线稿 + DOM 字幕层（讲史、科普最常用）
- Three.js 场景 + HTML 标签覆盖层

## 4. 和其他工具的关系

- 已经在用 **HyperFrames** 或 **Remotion** 的项目，沿用它们的工程结构和渲染器。本 skill 的导演稿、手艺规则和验收清单照样适用。
- **剪映 / Premiere** 适合做最后的拼接、加真人口播、调音乐。本 skill 出的 MP4 可以当素材导进去。
