# 动效手艺规则

这些规则是从合集里反复出现、而且写得最具体的做法里整理出来的。它们不是教条，每条都写了原因，遇到例外时按原因判断。

## 1. 转场

- **下一镜从上一镜的物体长出来。** 曲线变成票据边，数字变成金额，纸面线变成柱子的底座。观众的眼睛跟着那个物体走，就不会"断"。
- **默认不用交叉溶解和硬切。** 溶解显得犹豫，硬切需要动机。要用就有理由，比如卡在一个重拍上。
- **三种可靠的换场手段**：
  1. 同一个形状改尺寸、圆角、颜色；
  2. 用产品自身的形状当遮罩；
  3. 硬边纯色块扫过整个画面。色块要放大到超出画面四角，并用约 0.3 秒铺满，否则会出现单帧的大面积跳变。
- **出场方向决定下一镜的入场方向。** 向左离场，下一镜就从右边接进来，保持运动的连续性。
- **换色用色块扫过，不做两种颜色的混合渐变。** 混出来的中间色通常很脏。
- **容器和内容分开走。** 容器先变形，内容随后进入；下一次变形前，内容先退出。内容替换可以加一个约 12px、0.15 秒的短模糊。

## 2. 缓动与弹簧

- **不用线性运动。** 线性看起来像机器在挪东西。
- **入场用"快进慢停"**（outExpo，或 cubic-bezier(.16,1,.3,1)），**退场和擦除用加速离开**（inExpo）。
- **首选临界阻尼弹簧**：到位不过冲，显得干脆、有质感。确实需要弹性时，过冲不要超过约 2%。模板里的 `springSoft` 在 ζ=0.8 时约 1.5%。
- **同组元素错开 2–4 帧。** 同一帧一起起止显得僵；错开太多又显得拖。
- **一个值要多次换目标时**，把每次变化算成一段独立的弹簧，再叠加起来，而不是累积状态。模板里柱子的 7 次折叠就是这样写的。
- **镜头比主体晚安定**，比如主体阻尼 0.72、镜头 1.0。这样有"跟拍"的感觉。

## 3. 节奏

- **15 秒大约 4 个视觉主意，一镜一个。** 普通停留 0.5–1.5 秒；停留期间加 1.03–1.07 倍的缓推，避免画面冻住。
- **缓推用匀速，只在最后约 0.5 秒减速到 0。** 如果用两头慢的缓动（inOut）铺满整段停留，两端每帧移动不到 1 像素，看起来和冻住一样，冻结检测也会报出来。
- **快慢交替。** 高潮前留 0.3–0.5 秒蓄力。全片至少一次完全静止约 0.4 秒，连背景都停。
- **结尾全静止 1–1.2 秒。** 给观众读完、给平台留截图帧。循环片例外：循环片的末帧要等于首帧。
- **有音乐没配音时**：120 BPM 是最常见的选择（一拍 0.5 秒）。动作提前约 0.05 秒起步，才能刚好落在拍上。前 16 拍每拍都有事，之后可以隔拍。只把关键点卡在拍上，不是每个动作都卡。
- **背景的连续运动保持匀速**，不要每拍跳一格，否则看起来像卡顿。
- **有配音时**，旁白就是时钟，见 voiceover.md。

## 4. 镜头

- **二选一**：完全锁定，让物体自己动；或者只允许约 1.08 倍的缓推，加上卡在拍点上的横甩。
- **不要把镜头推进一个偏心的小点**，会产生侧甩。改成让这个点像光圈一样打开填满画面，光圈大小按面积缓动（半径按平方根变化）。
- **速度感靠拖尾和间距表现**，不靠镜头抖动。

## 5. 文字

- **同一时间屏上只有一层文字。** 两层文字同时动，观众一层也读不完。
- **可读信息至少停留 8 个干净帧**（30fps 下约 0.27 秒，这是最低限度）。整句要按正常语速读得完：中文约 4–5 字/秒。
- **竖屏字号**（以 1080 宽计）：关键词 ≥ 120px，字幕 48–56px，注释 ≥ 24px。正在读的字在 1080 画幅下至少 64px。
- **每行不要太长**：中文竖屏每行不超过约 16 字；英文每行 3–4 个词，字幕不超过 7 个词。
- **数字用等宽数字**（`font-variant-numeric: tabular-nums`），只在运动中滚动，落定要干脆。计数器读整帧时间，不读子帧时间，否则开运动模糊时数字会糊。
- **字母从遮罩线下升起**，比淡入更利落。
- **文字永远放 DOM 层**，不要画进 Canvas 或 3D，除非是特效字。
- **中英混排对齐**：用 DOM 的 flex 基线对齐（`align-items: baseline`）。不要用 canvas `measureText` 的墨迹框去算中文字高：它对 CJK 字形往往偏大约 10px，会让中英文基线错位。需要精确字形边界时，用 fontTools 从字体文件读。
- **字距**：中文标题加字距好看，但会把夹在里面的英文缩写（如 AI）拉散，给英文单独设字距。

## 6. 配色

- **3–4 色**：底色、主文字、辅助色、一个强调色。
- **强调色只给英雄物**：全片最重要的那个东西。到处都是强调色，就等于没有强调。
- **多阶段的片子**，可以让上一阶段的强调色变成下一阶段的主色，把换场串起来。
- **对比度至少 4.5:1。** 竖屏片子在手机户外光下看，浅灰字会消失。
- **高端品牌片普遍禁用**：霓虹渐变、紫色渐变、光晕、镜头光斑、网格地板。

## 7. 声音

- **一个可见事件配一个音效，其余留白。** 音效太满等于没有。
- **音效对齐到动作的瞬态**（落定的那一帧），不是动作开始的那一帧。
- **静音也要能看懂。** 大部分人刷短视频是静音的。
- **配乐在人声下让位**，响度目标约 -14 LUFS。混音命令见 voiceover.md。
- **不用版权音乐。** 可以用免版税曲库，或者用 Web Audio 或 Python 合成。

## 8. 打击反馈

- **分三档**：轻反馈每拍都可以有（小缩放、细线闪），中反馈偶尔出现（震屏、色块），大反馈全片只用 1–2 次（闪白、冲击波）。
- **每次只动一部分元素，几帧内结束。** 全屏都在抖，就没有重点了。
- **粒子只在最高潮放一次。** 彩带满屏飞是廉价感的头号来源。

## 9. 3D 补充

- **全片只用 2–3 种运镜**，每种对应一个叙事目的。
- **每个场景一个缓动运镜**：不连着推了又拉，运动不反向。尺度穿越时缩放在对数空间里插值。
- **俯仰角保持在 35–55°**；不正对着大平面往下拍。
- **正俯视时不要精确放在正上方**，否则相机朝向会突然翻转。停点速度要归零，防止补间过冲后反向。
- **镜头滚转时，文字要反向旋转保持可读。**
- **相关画面从同一个数据源算出来**，比如窗户、光柱和地面投影，保证彼此一致。
- **运动模糊只给运动物体**，不给正在读的字。
- **19 万个实例这种量级**，用实例化渲染逐个改位置、颜色。需要最后才揭示的文字，先用背景色搭好，最后翻面揭示。

## 10. 质感与颗粒

- "要有质感"通常靠三样东西：克制的配色、好字体、一层很淡的颗粒。不是靠光效。
- **颗粒要确定性**：启动时用种子随机生成 4–8 张噪点图，按帧号 `floor(t * fps) % N` 轮换，叠一层很低的不透明度（约 0.04–0.08）。不要每帧调用随机数现画。
- 颗粒会让 PNG 中间帧变大、渲染变慢（每帧可能翻倍）。预览用 `--fast`，终版再用默认。

## 11. 像素风补充

- 在低分辨率离屏画布上作画，整数倍放大，`imageSmoothingEnabled = false`，CSS `image-rendering: pixelated`。
- 坐标取整，固定色板（约 16–24 色），不用渐变和模糊阴影。
- 动作参数可以平滑插值，但每帧量化到网格上，看起来像 8–12fps 的手绘动画。
- 粒子用预分配的对象池，颜色随寿命按色板逐级变化。
